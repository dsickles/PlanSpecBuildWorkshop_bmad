# Claude Code

Claude Code is Anthropic's agentic coding tool that lives in your terminal and helps you turn ideas into code faster than ever before. It understands your codebase, executes routine tasks, explains complex code, and handles git workflows — all through natural language commands.

## Key Capabilities

| Feature | Description |
| :--- | :--- |
| **Codebase Awareness** | Understands your entire project structure and conventions without manual context setup |
| **Agentic Workflows** | Executes multi-step tasks autonomously — editing files, running tests, and iterating on results |
| **Terminal-Native** | Runs directly in your existing terminal, integrating cleanly with your tools and workflow |
| **Git Integration** | Handles commits, branches, PRs, and merge conflict resolution through natural language |
| **MCP Support** | Extensible via the Model Context Protocol to connect with external tools and data sources |
