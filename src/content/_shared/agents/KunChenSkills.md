# Kun Chen's Skills

Kun Chen's agentic engineering stack spans multiple repositories — Treehouse, Firstmate, and No Mistakes — rather than a single skills pack. Treehouse manages disposable git worktrees so parallel agent tasks do not collide. Firstmate is an agent distro you clone and talk to as one captain surface while it spawns and supervises a crew. No Mistakes sits as a local git proxy that runs an AI validation pipeline (review, tests, lint) before a clean push or PR reaches origin. Together they encode an L8 principal's workflow for coordinating agents safely at scale.
