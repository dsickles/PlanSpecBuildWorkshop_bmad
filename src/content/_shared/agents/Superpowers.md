# Superpowers

Complete agentic software development methodology built on composable skills — from brainstorming and design approval through subagent-driven development and TDD. Instead of jumping straight into code, Superpowers guides agents to elicit specs, present digestible design chunks, build implementation plans, and launch autonomous subagent-driven-development processes. Skills trigger automatically to enforce true red/green TDD, YAGNI, and DRY principles across Claude Code, Codex, Cursor, and other agents.
