A browser-based simulation game that teaches how to evaluate AI agents. The agent is already built. You decide, with evidence, whether it is good enough to ship. The first scenario is CartPilot, a grocery assistant that turns a dinner question into a ready-to-order cart. Everything runs in the browser: no backend, no API keys, and no live model calls.

Built with **Claude Code** and **Matt Pocock's skills**. This is an early prototype. A [live prototype](https://evalsim.vercel.app) is available to try.
